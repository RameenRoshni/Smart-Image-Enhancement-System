# Smart Image Enhancement & Analysis System
**DIP — Guided Project**

## Description
A complete image processing pipeline built with Python, OpenCV, and Streamlit.
Covers image acquisition, sampling, geometric transforms, intensity transformations,
and histogram processing.

## Installation
```bash
pip install opencv-python matplotlib numpy streamlit Pillow
```

## Run
```bash
# Terminal/script version
cd code
python main.py

# GUI version
cd code
streamlit run app.py
```
